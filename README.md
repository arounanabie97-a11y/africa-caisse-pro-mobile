
# AFRICA CAISSE PRO

Application professionnelle Android de gestion commerciale.

## Technologies
- Android natif Kotlin
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Impression thermique Bluetooth

## Fonctionnalités
- Gestion des commerçants
- Gestion des stocks et des prix
- Ventes et tickets de caisse
- Paiement Mobile Money au Burkina Faso
- Abonnement mensuel avec 7 jours d'essai gratuit
- Impression Bluetooth 58 mm et 80 mm
